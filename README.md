# dustint.dev — Portfolio

Dark, typographic portfolio for Dustin Tran. Built with Next.js (App Router),
TypeScript, Tailwind CSS v4, and anime.js v4.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Deploy

Push to GitHub and import the repo on [Vercel](https://vercel.com/new) — no
configuration needed.
